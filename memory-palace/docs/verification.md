## 水景靜心介面

- 以獨立 Canvas 2D 繪製潮汐、漣漪和靜光，桌面與手機直向、橫向皆可切換。原生 dialog 保留 Escape 關閉與焦點限制；直接入口和晚間回訪入口關閉後，焦點分別回到靜心與晚間回訪按鈕。
- 24 項 Node 測試通過，新增 5 項計時測試，涵蓋小數秒暫停續行、完成與重新開始、隱藏分頁期間的時間累積、時長驗證，以及到期邊界的暫停點擊。JavaScript 語法檢查與 diff 檢查通過。
- 使用 8766 與獨立暫存資料庫，實際操作開始、暫停、續行、3／5／10 分鐘選擇、風景切換、獨立靜態畫面及返回。暫停後隔開兩次截圖的完整像素相同；流動水面像素有變化，單獨關閉動畫後水面不變而計時繼續。
- 375 × 812 直向無水平溢出，靜心按鈕的觸控範圍皆至少 44 × 44 px；812 × 375 橫向使用緊湊控制列。這是瀏覽器尺寸檢查，未測實體手機效能。

- 靜心覆蓋莊園時不執行底層燈光與 WebGL 繪製，管家的行程更新仍執行。此介面沒有聲音或外部網路素材，不改動 Blender 模型、正式 Cycles 圖片、記憶地址與私人對話。

## V2 的運作邊界

- 目前尚未啟用即時 AI 推論。使用者交付的對話、貼上文字、文字檔和截圖會持久保存在本機，未設定 Agent 時狀態為 `awaiting_api`，待使用者之後提供 Agent。
- 預設 Agent 傳輸方式是由使用者指定的本機命令，使用 `memory-palace.agent.v1` JSON 標準輸入／輸出協定；OpenAI 相容 API 與 Anthropic 是選用 HTTP 傳輸。設定位於 Git 忽略的 `config/ai.env`。
- 不會自動擷取整個帳戶或其他生活資料來源。
- 記憶來源原文、整理摘要、想像助記分別保存；想像畫面不能當成真實經歷。
- 正式服務位於 `http://127.0.0.1:8765`。8766 僅用於暫時 QA。
