# Public character models

The selectable catalog in `app/character-catalog.js` contains only locally
hosted models whose files and licenses were checked. The original six robot
animals remain available as the default appearance.

| Model | Original source | License | Import audit |
| --- | --- | --- | --- |
| Quaternius Shiba Inu | https://quaternius.com/packs/ultimateanimatedanimals.html | CC0 1.0 (original `quaternius-license.txt`) | Self-contained GLB converted losslessly from author's embedded-data glTF, 1.7 MB, one skin, 12 named actions including `Idle`, `Walk`, `Eating` |
| RobotExpressive | https://github.com/mrdoob/three.js/tree/dev/examples/models/gltf/RobotExpressive | CC0 1.0 (original `robot-expressive-license.txt`) | GLB, 453 KB, two skins, 14 named actions including `Idle`, `Walking`, `Wave`, `Dance` |

Do not copy a paid or account-gated source from an unofficial mirror. When a
source becomes available, preserve the creator, license, original URL, and
unaltered source alongside any optimized web export.
